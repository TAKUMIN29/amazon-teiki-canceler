ROUTE / 使い方

3駅で完結する。

むずかしい設定はありません。改札を通るくらいの手数で、今の状態を確認して終わります。

STOP 01

ログインする

ボタンを押すと開くブラウザで、いつも通りAmazonにログイン。2段階認証もそのままで大丈夫です。

STOP 02

見る・選ぶ

定期おトク便の一覧が並びます。商品ごとに「何もしない」か「解約する」かを選んでいきます。

STOP 03

実行する

「テスト実行」を付けたまま導線を確認し、問題なければ外して本番実行。解約2件以上は文字入力での再確認も。

FARE TABLE / できること

5枚の切符に、できることをまとめました。

01 ／ LIST

一覧表示

次回お届け日・数量・価格をまとめて表示。今どれだけ定期便を抱えているか、一目で分かります。

02 ／ CANCEL

個別に解約

商品ごとにチェックして、まとめて実行。全部を同じ操作にする必要はありません。

03 ／ DRY-RUN

テスト実行

確定ボタンの手前で必ず立ち止まる、既定でONのモード。導線の確認だけなら何も実行されません。

04 ／ GUARD

誤操作防止

ブラウザが別のページに移動していたら、実行前に自動で検知して中止します。無関係な商品を巻き込みません。

05 ／ SPEED

高速化

一覧の読み込みを高速化。待たされてイライラする時間を減らしました。
